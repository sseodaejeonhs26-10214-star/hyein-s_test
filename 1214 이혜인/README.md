# 우리 곁으로 — 실종 동물 찾기

설치나 회원가입 없이 사용하는 HTML·CSS·JavaScript 연습용 웹앱입니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 열어주세요. 지도는 인터넷 연결이 필요합니다.

파일 열기 방식에서 브라우저 저장 또는 위치 기능이 제한되면 이 폴더에서 아래 명령을 실행한 뒤 http://localhost:8000 을 열어주세요.

```powershell
python -m http.server 8000
```

## 사용 순서

1. ‘실종 동물 등록’을 누르고 사진·특징·실종 일시·장소를 입력합니다.
2. 등록 창 안의 지도를 눌러 위치를 선택하고 등록합니다. 지도 연결이 안 되면 위도·경도를 직접 입력할 수 있습니다.
3. 지역·이름, 종류, 상태, 등록 기간으로 검색합니다.
4. 목록이나 지도에서 상세 정보를 열어 목격 제보를 저장합니다.
5. 동물을 찾으면 ‘찾았어요 처리’를 누릅니다. ‘상태 → 찾았어요’에서 다시 확인할 수 있습니다.

## 파일

- `index.html`: 화면과 입력 양식
- `style.css`: 모바일 대응 디자인
- `app.js`: 지도, 검색, 등록, 제보, 브라우저 저장

## 범위

이 버전은 서버 없는 단일 브라우저 시제품입니다. 등록·제보 데이터는 localStorage에 저장되어 새로고침 후에도 유지되지만, 브라우저 데이터를 삭제하면 사라집니다. 다른 기기나 사용자에게 공유되지 않습니다. 사진은 JPG·PNG·WebP, 파일당 최대 2MB이며 브라우저 전체 저장 용량의 제한을 받습니다.

실제 연락처 공개, 사용자 간 메시지 전송, 주변 실종 알림과 주인 없는 동물 제보는 구현하지 않았습니다. 서비스로 운영하려면 서버·데이터베이스·로그인·게시글 소유자 권한과 메시지/알림 기능을 추가해야 합니다. 이 시제품에서는 같은 브라우저의 모든 글을 ‘찾음’으로 변경할 수 있습니다.

지도는 Leaflet 1.9.4와 OpenStreetMap을 사용합니다. 참고: https://leafletjs.com/
